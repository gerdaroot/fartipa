# Рисуй на говне

Авторы: gerda, okurok51, yamoo

Нативная игра для iPhone на Swift, без браузера внутри. Поверхность считается как настоящий рельеф: палец продавливает канавку с валиками по краям, свет ложится по рельефу.

- **Рисовать**: три толщины пальца, «Загладить», «Новая куча», «Пук», сохранение картины.
- **Обводить фигуры**: шесть уровней, очки за покрытие контура и точность, до трёх звёзд. Следующий уровень открывается с одной звезды.
- **Говнобайкер 3Д**: мчишь по трассе из той же кучи, собираешь говнокоины и уворачиваешься от струй мочи с неба. За коины в гараже покупаются байки и прикиды. Звёзды за фигуры тоже дают коины, а твоя последняя картина висит на щитах вдоль дороги.
- **Звуки**: 16 записей пердежа из `ios/PoopDraw/Sounds`. Файлы `hard-*` взяты из Telegram-канала @pooppoppoop. Идут по кругу в случайном порядке: запись повторится, только когда сыграют все остальные. Играют от кнопки «Пук», на новой куче, иногда после мазка и при нуле звёзд. Звук идёт и при выключенном переключателе на корпусе.

## Устройство

| Папка | Что внутри |
|---|---|
| `ios/PoopDraw/Core` | Логика без зависимости от iOS: рельеф, очки, мухи, синтез. Тестируется через `swift test` |
| `ios/PoopDraw/Game` | Экран рельефа, касания, мухи, звук, состояние игры |
| `ios/PoopDraw/UI` | Экраны и кнопки на SwiftUI |
| `scripts` | Скриншоты всех экранов из симулятора; GitHub кладёт их в ветку `screenshots` |
| `prototype-web` | Первая версия на HTML. В приложение не входит |

## Как поставить на iPhone

Для сборки нужен macOS: на Windows приложение для iOS не собрать.

**С компьютера на Windows, через GitHub**

1. Залей папку в свой репозиторий на GitHub, ветка `main`. Actions прогонит тесты и соберёт `PoopDraw.ipa` без подписи.
2. Скачай файл со страницы запуска во вкладке Actions, раздел Artifacts.
3. Поставь его через [Sideloadly](https://sideloadly.io) со своим Apple ID. С бесплатным аккаунтом приложение работает 7 дней, потом его нужно поставить заново.

**На Mac**

```sh
brew install xcodegen
xcodegen generate
open PoopDraw.xcodeproj
```

В Xcode выбери свою команду в Signing & Capabilities и запусти на телефоне.

## Тесты

```sh
swift test
```

Без Mac то же самое можно запустить в Docker:

```sh
docker run --rm -v "$PWD":/app -w /app swift:6.1 swift test
```
